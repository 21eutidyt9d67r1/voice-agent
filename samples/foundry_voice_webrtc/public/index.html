Quick setup & connection notes
  1. Configure your Foundry project endpoint in .env. No existing Agent or Agent name is required: the demo uses webrtc-personalized-hd-demo by default. Set AZURE_VOICE_AGENT_NAME only to choose a different saved Agent.
  2. Install Azure CLI, open a normal PowerShell window, and run az login. Use the tenant/subscription containing your project. Agent Service requires Microsoft Entra ID, not a resource API key; no client secret is needed. Your account needs permission to read, create, enable, and use Agents.
  3. If no Agent exists, select Create Agent & start. The demo creates and saves the Agent before requesting microphone access. Later visits reuse it automatically. Choose a connection and allow the microphone. WebSocket needs no STUN/TURN; WebRTC needs ICE connectivity.

Credentials stay on the backend. Run the server as the same Windows user who ran az login, with outbound network access. After Agent setup, check authentication and session startup with python check_websocket.py.

First visit: create and save an Agent, then talk. Future visits: reuse the saved Agent. Existing definitions are preserved; missing Agents use the bundled personalized example. Azure creation requires appropriate permissions and may incur usage charges.
