Export now, publish here or through the Foundry API later

Publication contract

This export is the definition, not the entire API request.

  1. Choose the destination Agent name. The name belongs in the URL, not in this file.
  2. Send POST /agents/<agent-name>/versions?api-version=v1.
  3. Wrap the exported object in the request below and send it as JSON.
{
  "definition": { "...": "this export" },
  "description": "Optional version description",
  "metadata": {},
  "draft": false
}

Release: use "draft": false.

Draft: use "draft": true.

Required headers: Authorization, Content-Type: application/json, and Foundry-Features.

The page-level Publish & run button builds this wrapper automatically. Copy publish body copies a complete JSON request body for external publication.
